Sobre el Proyecto

🎨 Temática y Decisiones de Diseño

Elegimos una temática gastronómica cálida y cercana. La paleta de colores combina tonos tierra y anaranjados (#4a2c1a, #e8590c y #fff4e6) que evocan la cocina casera y garantizan un alto contraste de lectura. El diseño sigue una metodología mobile-first con tarjetas de bordes redondeados y transiciones suaves para una navegación fluida en cualquier pantalla.

🌐 Información sobre la API

Los datos se consumen de forma dinámica desde la API pública DummyJSON Recipes (dummyjson.com/recipes). De cada registro extraemos el nombre del plato, imagen, tipo de cocina, tiempo de preparación, dificultad y calificación, permitiendo además búsquedas en tiempo real mediante su endpoint /search.

⚙️ Detalles Técnicos del Desarrollo

La aplicación está construida con HTML5 semántico, CSS3 con variables nativas y JavaScript modular (ES Modules) separado por responsabilidades (obtención de datos, modelado con clases y renderizado en el DOM). Incluye control de estados de carga, manejo de errores con opción de reintento y optimización de búsqueda con debounce.
